# 11/21(토) 실험 2·3 현장 안내

A·B 둘이 한다(C 불참, DECISIONS D-79). 1부는 B에게 보내는 안내, 2부는 내일 둘이 보면서 진행할 표다. 자세한 절차의 원본은 `docs/PROTOCOL.md` §3·§4다.

---

## 1부. B에게

내일은 실험 2(템포 챌린지)와 수직 점프, 실험 3(다리 진자)을 둘이 끝낸다. 한 사람이 걷는 동안 다른 사람이 도우미를 하고 순서를 바꾼다. 한 사람에 약 1시간이다. **12:40 집합**(장소는 A가 따로 알린다), 13:00부터 코스를 설치한다.

**오늘 밤 준비**

- [ ] Sensor Logger 설정: 가속도계, 중력, 자이로스코프, 위치, 걸음 수, 보정 안 한 가속도계·자이로스코프. 샘플링 100 Hz(10 ms). 백그라운드·위치 권한 허용, 배터리 최적화에서 Sensor Logger 빼기
- [ ] 이미 올린 옛 기록은 앱에서 지워 자리 만들기(무료판은 저장 개수 제한이 있다)
- [ ] 템포 음원 30개(100–245 BPM)를 폰에 받아 두기(없으면 A에게)
- [ ] 폰 카메라: 0.5배 광각에서 60 fps가 되는지, 슬로모션 120 fps 이상이 되는지 확인. A가 걸을 때 B 폰이 메인 카메라다
- [ ] 저장 공간 비우기(영상), 완전 충전, 보조배터리
- [ ] 체중·키 재 오기(다리 길이는 현장에서 잰다)
- [ ] 챙길 것: 실험 1 허리 파우치, 이어폰, 운동화

**꼭 지킬 것**

- 내보낸 파일 이름을 바꾸지 않는다. 분석이 기록 시각으로 시행을 맞춘다(실험 1 때는 이름을 바꿔 올렸다).
- 블록이 끝날 때마다(무음 2개, 단계마다 2개, 점프 1개, 진자 3개씩) Sensor Logger에서 **Zipped CSV로 내보내 카톡으로 A에게** 보낸다. A가 바로 점검해서 통과·다시를 알려 준다. 앱에서 지우는 것은 A가 '받음'이라고 한 뒤에만 한다.
- 걸을 때 지시: **"박자 하나에 한 발씩 맞춰 이동해 주세요. 걷든 뛰든 편한 대로."**
- 키·체중·다리 길이는 분석에 쓴다. 저장소가 공개라서 **공개 저장소에 올려도 되는지** 알려 줘. 안 되면 공개하지 않는 방법으로 둔다.

## 2부. 현장 진행표

### 기기와 역할

| | A가 걸을 때 | B가 걸을 때 |
|---|---|---|
| 센서·음원(허리 파우치) | A 폰 | B 폰 |
| 메인 카메라(고정, 60 fps, 0.5배) | B 폰 | A 폰 |
| 발 카메라·스톱워치 | 아이패드 | 아이패드 |
| 파일 보내기 | A가 바로 | B → 카톡 → A |

### 도착하면

- [ ] 배터리 80% 이상, 방해 금지 모드(알림 진동이 센서에 섞이지 않게)
- [ ] 코스: 미끄럽지 않은 평지 직선 40 m, 0·5·35·40 m 표시(분석은 5–35 m). 진자용 계단 한 칸
- [ ] 메인 카메라: 20 m 지점 맞은편 10–15 m, 0.5배, 60 fps, 삼각대나 가방에 고정
- [ ] 발 카메라(아이패드): 25–30 m 지점, 메인 카메라 반대편, 코스에서 4–5 m, 발목~무릎 높이에 가방으로 고정, 1배·가로·슬로모션(240, 안 되면 120 fps). 발과 바닥이 크게, 4–5걸음이 들어오게
- [ ] 조회표 `docs/field/exp2_lookup.pdf`를 폰에 열어 두기
- [ ] 원격 점검 연결 확인(A 폰)
- 늦어도 14:00에는 시작한다(일몰 17:20 전후, 영상 밝기)

### 한 사람 순서 (A 걷기·B 도우미 → B 걷기·A 도우미)

1. [ ] 마커 3개를 카메라 쪽 다리에: 대전자, 무릎 바깥 관절선, 바깥 복사뼈
2. [ ] **무음 2회**: 도우미가 아이패드 스톱워치로 5→35 m 시간 t와 걸음 수 N을 잰다 → 현장 PC = N ÷ t × 60(두 회 평균) → 조회표로 음원 5개를 골라 기록지에 적는다 → 두 기록을 보내고 **점검 답을 받은 뒤** 100% 시작
3. [ ] **100 → 120 → 135 → 150 → 165%**, 단계마다 2회, 방향은 번갈아. 단계가 끝날 때마다 두 기록을 보내고 쉬는 동안 답을 받는다
4. [ ] 135% 이상: 발 카메라를 단계마다 한 번 켜서 두 시행을 이어 찍는다(켤 때 단계를 소리 내어)
5. [ ] 165%에서도 걸으면(영상 판정) 180%·195%를 1회씩 더
6. [ ] 1분 쉬고 **수직 점프**
7. [ ] **다리 진자**

### 시행마다

1. [ ] 걷는 사람: 기록지의 BPM 파일 고르기 → Sensor Logger 기록 시작 → 음원 재생(무음은 이어폰만) → 폰을 실험 1과 같은 방향으로 파우치에 넣고 끈을 꽉 조인다
2. [ ] 도우미: 메인 카메라 녹화 → 시행 번호를 소리 내어 읽기(음성 슬레이트)
3. [ ] 걷는 사람: 카메라에 보이는 곳에서 작은 점프 3번(발이 확실히 뜨게) + 박수 → 출발점에서 출발해 40 m 끝까지
4. [ ] 기록 끝. 파일 이름 바꾸지 않기
5. [ ] 도우미가 기록지 한 줄: 주자, 시행 번호, 비율, 실제 BPM, 방향, (무음) t·N, 걷기/뛰기, 메모

### 수직 점프 (§3.7)

- [ ] 폰은 파우치에 그대로, 새 기록 시작
- [ ] 옆에서 슬로모션 120 fps 이상(메인 폰이 안 되면 아이패드)
- [ ] 손은 허리 → 2초 가만히 → 다른 동작 없이 바로 반동해서 최대로 → 제자리 착지(무릎 굽혀 부드럽게). 3회, 사이 20–30초
- [ ] 기록 끝 → 보내기. 기록지에 영상 파일 이름과 fps

### 다리 진자 (§4)

- [ ] 길이: 다리(대전자→바닥), 허벅지(대전자→무릎 바깥 관절선), 정강이(무릎 관절선→바깥 복사뼈)
- [ ] 마커 붙인 다리의 정강이에 폰 밴드. 6회 동안 다시 차지 않고, 카메라는 그 다리 쪽에
- [ ] 계단 한 칸에 한 발로 선다(난간 잡아도 된다). 시행마다 새 기록
- [ ] **곧은 다리 3회**: 엉덩관절 힘을 빼고 무릎은 펴서 고정. 15번 이상(약 25초) 흔들고, 약해지면 살짝 다시 민다
- [ ] **굽힌 다리 3회**: 무릎 90°를 허벅지 뒤 근육으로 계속 붙잡아 'ㄴ'자 한 덩어리로 흔든다(정강이는 뒤로, 바닥과 거의 평행)
- [ ] 곧은·굽힌 다리 각 1회는 옆에서 촬영(10번 흔들리는 시간, 굽힌 다리는 무릎 각이 보이는 프레임). 기록지에 영상 이름과 fps
- [ ] 곧은 3회, 굽힌 3회가 끝날 때마다 보내기

### 다시 하는 기준

- **다시:** 파일이 안 열리거나 끊김, 걸음 구간 이상, 점프가 3개로 안 잡힘, 진자 10주기 미만, 굽힌 다리인데 무릎이 펴짐
- **확인:** 싱크 점프가 3개로 안 잡히면 영상에 점프 3번과 박수가 보이는지 본다. 보이면 그대로, 빼먹었으면 다시
- **다시 안 함:** 달린 시행에서 체공이 적게 잡히거나 스프링 값이 빈칸인 것(예상된 것, D-74)
- 다시 할 시행은 다음 단계로 가기 전에 바로. 앞 시도는 기록지에 `valid=0`
- 점검 답이 5분 넘게 없으면 그대로 진행하고, 다시 할 것은 그 사람 챌린지 끝에 몰아서
- 원격이 끊겨도 실험은 그대로 한다. 점검은 저녁에, 다시 할 것은 예비일(11/22)에

### 마무리

- [ ] 모든 zip은 이름 그대로, 영상 백업, 기록지 두 장(실험 2, 진자)
- [ ] Sensor Logger에서 지우는 것은 '받음' 확인된 기록만
- [ ] 데모 촬영은 시간이 남을 때만(분석에 쓰지 않는다)
