# 내 플레이리스트가 걸음을 바꾼다 — 총정리본

음악 템포에 따른 보행 동조와 진자 역학. Healthcare Biomechanics 팀 프로젝트(A·B·C 3명). 2026-11-23 작성.

- 숫자의 출처는 `results/`의 결과 표(2026-11-22 실행, 데이터 동결 전)와 검산표 [총정리본_검산표.csv](총정리본_검산표.csv)다. 검산표는 `tools/handcalc_check.py`가 만든다.
- 정의·판정 기준·문턱은 `docs/SPEC.md`, `docs/DECISIONS.md`, `config/params.toml`을 따랐다.
- 사람은 A·B·C로만 쓴다.
- 교안 쪽 번호와 예제 입력은 교안 원본 PDF(2–12주차, 11개 파일)와 맞춰 본 값이다(11/23). 저장소에는 교안 원본이 없다. 교안 슬라이드에는 문제와 입력만 있어서 풀이 값은 모두 우리가 푼 값이다.
- 손계산은 결과 표의 원값으로 했고 본문에는 반올림해 적었다. 적힌 숫자로 다시 계산하면 끝자리가 다를 수 있다.

**상태 표시**

| 표시 | 뜻 |
|---|---|
| 실측 | 우리 측정값으로 계산했다 |
| 참고값 | 측정은 했지만 표본이 매우 적거나(접촉 1–3개 등) 정밀도가 낮아 참고로만 쓴다 |

## 0. 한 장 요약

**질문.** 듣는 음악의 템포가 걸음을 바꾸는가. 박자에 맞추라고 하면 어디까지 맞추는가. 걷기와 달리기가 바뀌는 지점과 편한 걸음 박자를 진자 역학으로 설명할 수 있는가.

**실제로 한 것.** 실험 1(일상 보행)은 A 10회, B 15회, C 5회를 걸었다. 실험 2(템포 챌린지), 실험 3(다리 진자), 수직 점프는 11/21에 A·B가 했다. 허리나 정강이에 찬 폰의 가속도·자이로·위치 기록과 영상으로 케이던스, 동조율, 속도, 충격, 체공, 진자 주기를 냈다(2장).

**가설별 결과(기준을 채운 사람 수).** 값과 기준은 3장에 있다.

| 가설 | 내용 | 기준을 채운 사람 |
|---|---|---|
| 1 | 곡 템포가 평소 케이던스(PC)에 가까우면 지시 없이도 걸음이 박자 쪽으로 끌려간다 | 3명 중 1명(A) |
| 1-2 | 박자에 맞추라고 하면 +20%까지 맞춘다 | 2명 중 0명 |
| 2 | 빠른 곡일수록 충격이 크다 | 3명 중 1명(A). B는 관계 없음, C는 반대 방향 |
| 2 | 빠른 곡일수록 더 빨리, 더 큰 보폭으로 걷는다 | 판정한 2명 중 1명(A). B는 판정 불가 |
| 2 | 억지로 맞추면 걸음 변동성이 더 크다 | 2명 중 1명(B) |
| 3 | 달리기로 바뀌는 지점이 Fr 0.5 근처다 | 2명 중 1명(A) |
| 4 | 다리 진자의 예측 케이던스는 실측 PC보다 느리다 | 2명 중 2명 |

**처방 범위.** A는 일상 PC의 102.9%(BPM 102.6)부터 현장 PC의 104.3%(BPM 105.0)까지다. 두 값은 기준 PC가 다르다. B는 일상 PC의 105.1%(BPM 103.0)부터이고 상한은 없다. C는 없다(3.5).

**손계산 검증.** 손계산 120개(결론 14, 교안 짝 38, 교안 예제 50, 가정 예시 18)의 값 857개를 결과 표의 원값으로 다시 풀었다. 결론 손계산 14개와 교안 예제 짝 손계산 20개, 합해 34개 가운데 코드 출력이 있는 21개는 견준 값이 모두 코드와 같았다. 표 전체로는 코드 값과 견준 307개가 모두 일치했다. 교안 예제와 가정 예시는 견줄 코드 출력이 없다(4장).

**교안 연결.** 연결표는 55짝이다: 실측 38, 참고값 4, 계산만 8, 끊김 1, 개념만 3, 값 없음 1. 8주차는 중간고사라 강의가 없었다. 교안 원본의 예제 50개도 모두 풀어 검산표에 넣었다(4.3, 5장). 재지 않은 교안 내용은 가정 예시 18개로 이었다(6장).

## 1. 연구 질문·가설·설계(계획)

계획은 다음과 같았다(`docs/SPEC.md` §2).

| 가설 | 내용 | 한 사람에서 기준 |
|---|---|---|
| 1 | 곡 BPM이 PC ±10% 안이면 지시 없이도 걸음이 박자 쪽으로 끌려간다 | 곡 구간 단위 Spearman ρ(T, ΔC%) > 0이고 p < 0.05, 그리고 PC ±10% 안의 곡에서 동조율이 그 밖의 곡보다 높다 |
| 1-2 | 박자에 맞추라고 하면 +20%까지 맞춘다 | 실험 2의 100%와 120% 단계 각각에서 ±3% 안 걸음이 80% 이상 |
| 2 | 빠른 곡일수록 더 빨리, 더 큰 보폭으로 걷고 충격이 크다. 억지로 맞추면 걸음 변동성이 더 크다 | ρ(T, 속도), ρ(T, 보폭), ρ(T, 충격)이 양수면 '증가 경향'. 변동성은 같은 템포의 실험 1과 실험 2를 비교 |
| 3 | 템포를 올리면 어느 지점에서 달리기로 바뀌고, 그 지점이 Fr ≈ 0.5다 | 마지막으로 걸은 단계와 처음 뛴 단계 사이에 Fr 0.5가 들어간다 |
| 4 | 곧게 편 다리 진자의 예측 케이던스는 실측 PC보다 느리다 | C_pend < PC. 흔들림 주기의 예측과 실측의 평균 오차가 15% 이내면 모델이 타당하다 |

| | 실험 1 · 일상 보행 | 실험 2 · 템포 챌린지 | 실험 3 · 다리 진자 |
|---|---|---|---|
| 조건 | 무음 3회 + 플레이리스트 P1–P4 각 3회 = 1인 15회 | PC의 100·120·135·150·165% 음원, 단계마다 2회. 165%에서도 걸으면 180·195%. 끝에 수직 점프 3회 | 곧은 다리 3회 + 무릎 90° 굽힌 다리 3회 |
| 한 번 | 평소 길 8분 이상 | 40 m 코스(가운데 30 m 분석) | 다리를 흔든다 |
| 지시 | 없음 | 박자 하나에 한 발씩, 걷든 뛰든 | 힘을 빼고 흔든다 |
| 폰 | 허리 | 허리 | 정강이 |

n = 3이라 집단 검정을 쓰지 않고 사람마다 판정하기로 했다. 기호는 T = 템포 비율(%), PC = 평소 케이던스(걸음/분), ΔC% = 케이던스 변화율, S3 = ±3% 동조율, P = 다리 흔들림 주기(s), Fr = Froude 수다(부록 D).

## 4. 손계산으로 검증한 과정

### 4.1 방법

1. 잰 값: 결과 표(`results/*.csv`), 영상에서 읽은 값(`data/video_markers.csv`, `data/video_exp2.csv`), 몸 치수(`data/participants.csv`)에서 입력을 읽었다.
2. 손계산: 분석 코드를 거치지 않고 식을 그대로 풀었다(`tools/handcalc_check.py`).
3. 코드 값: 파이프라인이 결과 표에 써 둔 값을 읽었다.
4. 비교: 손계산 값에서 코드 값을 뺐다. 차의 크기가 값의 10⁻⁹배 이하면 일치로 봤다.

- 기존 `pytest` 230개는 예시 입력(체중 60 kg, 다리 0.90 m 등)으로 '손계산 = 코드'를 확인했다. 이번 검산은 실측 입력으로 같은 일을 했다. 검산 도구의 테스트 12개를 더해 242개가 통과했다(11/23).
- 검산 기준값은 11/22–23에 결과 표의 표시값(반올림한 값)으로 손계산한 값이다. 이번에는 원값으로 다시 풀고 기준값과도 견줬다(4.4).
- 예외가 하나 있다. HC-A6의 걸음 시각은 결과 표에 없어서 원자료를 분석 코드의 걸음 검출로 다시 읽었다. 세는 일만 손으로 했다.
- 검산표는 값마다 한 줄이다. 열은 id, 구분, 교안, 입력, 식, 손계산 값, 코드 값, 차이, 일치, 상태, 항목, 검산 기준값, 기준값과 같은지다.

### 4.2 결론으로 가는 손계산

형식은 교안 → 입력(출처) → 식 → 손계산 값 → 결론 → 상태다. 값은 검산표의 같은 id 줄에 있다.

**HC-A1 평소 케이던스 PC** (5주차 케이던스 p6–8)
- 입력: 무음 회차 케이던스 A 100.25, 99.19 / B 97.26, 100.34, 96.40 / C 118.54 걸음/분 (`results/walks.csv`: `cadence_median_spm`).
- 식: PC = 무음 회차 평균.
- 값: A 99.72, B 98.00, C 118.54 걸음/분.
- 결론: A·C는 무음 3회 미만이라 임시값이다.
- 코드 값과 견준 3개가 모두 일치했다. 상태: 실측.

**HC-A2 실질적 변화 기준 SESOI**
- 입력: HC-A1의 무음 회차 케이던스.
- 식: SESOI = max(표본 SD ÷ 평균 × 100, 1).
- 값: A SD 0.748, 변동계수 0.75% → 1.00%. B SD 2.069, 2.11% → 2.11%. C는 무음 1회라 변동계수를 낼 수 없어 하한 1.00%(임시값).
- 결론: A·C는 하한 1.0%, B는 2.11%를 기준으로 썼다.
- 코드 값과 견준 5개가 모두 일치했다. 상태: 실측.

**HC-A3 템포 비율 T**
- 입력: 곡 BPM(`results/segments.csv`: `bpm`), 튼 BPM(`results/exp2_summary.csv`: `bpm_played`), PC와 현장 PC(`results/exp2_pc.csv`: `pc_field_spm`).
- 식: 실험 1은 T = BPM ÷ PC × 100. 실험 2는 T = 튼 BPM ÷ 현장 PC × 100.
- 값: 예로 A의 PC 99.72에 120 BPM 곡이면 T = 120.3%. 실험 2 A 100% 단계는 105 ÷ 100.7 = 104.3%, 120% 단계는 125 ÷ 100.7 = 124.1%. B 100% 단계는 115 ÷ 117.6 = 97.8%.
- 결론: 실험 2의 13단계와 실험 1의 플레이리스트 평균 12개(3명 × P1–P4)를 손으로 다시 냈다.
- 코드 값과 견준 25개가 모두 일치했다. 상태: 실측.

**HC-A4 케이던스 변화율 ΔC%와 실질적 변화**
- 입력: 곡 구간 케이던스(`results/segments.csv`: `cadence_median_spm`), PC, SESOI.
- 식: ΔC% = (C − PC) ÷ PC × 100. |ΔC%| > SESOI이면 실질적 변화다.
- 값: 플레이리스트 평균은 3.3의 표와 같았다. A는 P1–P4 모두 +1.0%를 넘었다. B는 모두 +2.11%를 넘었다. C는 모두 음수였다.
- 교차 확인: 속도 표의 v ÷ 보폭 × 60이 A 무음 99.72, C 무음 118.54로 각자의 PC와 같았다. 플레이리스트별 케이던스 변화도 위 ΔC%와 0.20%p 안에서 같았다(속도 표는 속도가 있는 구간만 평균한다).
- 결론: 실질적 변화를 넘은 플레이리스트는 A 4개, B 4개(모두 빨라짐), C는 P1·P2·P4가 느려진 쪽이었다.
- 코드 값과 견준 12개가 모두 일치했다. 상태: 실측.

**HC-A5 가설 1: Spearman ρ를 손으로 계산**
- 입력: `results/segments.csv`의 사람별 곡 구간 (T, ΔC%). A 25개, B 46개, C 13개.
- 식: 두 열을 각각 순위로 바꾸고 d = 순위 차이를 구한다. 같은 값이 없으면 ρ = 1 − 6Σd² ÷ (n(n² − 1))이고, 있으면 순위의 피어슨 상관으로 계산한다(같은 값은 평균 순위).
- 값: A는 같은 곡을 두 번 들어 T에 같은 값이 있었다. 그래서 순위의 피어슨 상관으로 냈다: ρ = +0.64. Σd² = 936.5이고, 같은 값이 없을 때의 식으로는 0.6398이다. B는 −0.17, C는 +0.12였다.
- PC ±10% 곡의 S3 평균과 그 밖의 곡: A 54.1% / 6.7%, B 61.7% / 2.8%, C 40.7% / 3.9%.

### 5.3 교안 원본과 대조한 결과

- 이 문서가 인용한 교안 쪽은 모두 원본과 맞춰 봤다. 주차·쪽·예제 번호·주제와 예제 입력값이 모두 같다.
- 원본에 풀이 숫자가 찍힌 곳은 세 곳뿐이다.
  - 10주차 p15 예제 4 그림: F_rx = 70.7 N, F_f = 114.79 N. '움직이지 않는다'는 결론은 없다.
  - 11주차 p20–21: θleg = tan⁻¹(3.23) = 72.8°, θthigh = tan⁻¹(−3.625) = −74.6° → +180° = 105.4°.
  - 10주차 p11 예제 1 그림: W = 510 N, R_x = 300 N, R_y = 1800 N.
- 교안이 묻지 않은 것을 우리가 더 푼 값. 본문에서 '우리가 더 푼 값'이라고 썼다.
  - 10주차 예제 1의 a_x(교안은 수직 가속도만 묻는다).
  - 12주차 p59 예제 1의 근육 힘 3,495 N(교안은 근육 모멘트만 묻는다).
  - 손계산 노트 4번의 최고 높이 5.10 m, 5번의 '체공 0.69 s, 높이 0.59 m'.
- 8주차는 중간고사다. 9주차 교안 p2 일정표에서 8주(2026-10-20–10-26)는 Mid-term Exam이다. 강의가 있었던 주차는 2, 3, 3-2, 4, 5, 6, 7, 9, 10, 11, 12주차다.
- 원본에서 찾지 못한 것(교안 출처로 쓰지 않았다). 원본 전체를 검색해 확인했다.
  - '9주차: 달리기는 스프링'이라는 문장과 Morin 식(F_max = mg(π/2)(t_f/t_c + 1)). 9주차에는 탄성력 F = kΔs(p39)와 탄성에너지 SE = ½kΔx²(p51)만 있다. 'spring'은 이 두 쪽의 스프링 상수뿐이다.
  - 4주차의 청각 경로('귀 → 뇌 → 척수')와 'CPG를 박자 쪽으로 조정한다'는 설명. 4주차 p7에는 '뇌는 외부 환경의 해석자', '척수에는 반사와 CPG 회로가 있다'만 있다.
  - 물리 진자 주기 식 P = 2π√(I ÷ mgd). 교안에는 τ = Iα, 관성모멘트, 평행축 정리만 있다(작은 각 근사로 유도한 교안 밖 식). 진자·주기 식·Froude·역진자·음악·리듬은 원본에 없다.
  - Zijlstra & Hof 역진자 보폭 식, Winter·Dempster 분절 비율 값(0.100, 0.433, 0.323, 0.061, 0.606, 0.416), Kram 외(1997)의 Fr 0.5, Perera 외(2006)의 0.05 m/s는 참고문헌이다. 다만 회전반경을 분절 길이의 비율로 두고 I = m(ρl)²로 내는 방법은 12주차 p27에, 평행축 정리는 p30에 있다.

## 6. 측정하지 않은 교안 내용: 가정 예시

각 예시는 '우리 실측 상태 + 가정값 → 그랬다면'의 형식이다. 가정값에는 '가정'이라고 적었다. 교안에 없는 상수는 '교안 밖 가정'이라고 적었다. 계산은 검산표에 '가정 예시'로 들어 있다. 가정 예시의 값은 측정 결과가 아니다.

**G-1 응력·변형률(3주차 p6 σ = F/A, p8 ε = ΔL/L, p10 E = σ/ε·곡선 기울기 = 강성, p15 뼈는 강성 재료·연골은 유연 재료, p25 극한 응력 그림)**
- 실측: A의 발 디딤 충격 1.60 BW = 1,099 N(걷기 무음), 3.78 BW = 2,597 N(180% 뛰기). 정강이 0.36 m.
- 가정: 정강뼈가 지면반력만 받는다. 단면적 n = 3.0 cm²(가정). E는 교안 p10 표의 뼈 값 18,000(표에 단위가 없어 MPa로 봄).
- 계산: 걷기 σ = 1,099 ÷ 3.0×10⁻⁴ = 3.66 MPa, ε = 0.020%, ΔL = 0.073 mm. 뛰기 8.66 MPa, 0.048%, 0.173 mm. 같은 응력이면 표의 연골(20)은 18.3%·43.3% 변형된다.
- 뜻: 뼈는 '단단한 재료'라 같은 힘에서 연골보다 약 900배 적게 변형된다.
- 교안 그림 값(p25, 그림 읽기): 사람 성인 피질골의 극한 응력은 압축 약 200, 인장 약 135, 전단 약 70 MN/m²(= MPa)다. 걷기 3.66 MPa는 압축 극한의 1/55, 뛰기 8.66 MPa는 1/23이다(인장 기준 37배, 16배).

**G-2 점탄성과 하중률(3주차 p25–26)**
- 실측: 위의 두 충격.
- 가정: 정점까지 걸리는 시간이 걷기 0.10 s, 뛰기 0.03 s.
- 계산: 하중률은 16 BW/s(11.0 kN/s)와 126 BW/s(86.6 kN/s)로 약 7.9배다.
- 뜻: 교안대로 뼈는 빠르게 하중을 받을수록 더 많은 에너지를 흡수한다. 템포를 올려 뛰면 하중률이 크게 오른다.

**G-3 하중 종류(3주차 p27–28)**
- 연결: 걷기·점프에서 정강뼈는 압축을 받는다. 진자에서 엉덩관절은 흔드는 다리를 끌어당기는 인장을 받는다(G-10의 118.2 N).

**G-4 수축 유형과 힘-속도(3-2주차 p31 원심성에서 최대 힘, p35 곡선)**
- 실측: A 점프 1의 이륙 속도 2.587 m/s, 밀기 일 437.5 J(HC-B18, 동심성).
- 가정: 착지 때 몸 중심이 n = 0.30 m 내려가며 멈춘다.
- 계산: 흡수할 에너지 = ½mv² + mgn = 234.3 + 206.0 = 440.3 J(원심성). 평균 지면반력 = m(g + v² ÷ 2n) = 1,468 N(2.14 BW). 뻣뻣하게 n = 0.10 m로 멈추면 303.0 J, 3,030 N(4.41 BW).
- 뜻: 밀 때 동심성으로 낸 일만큼 착지 때 원심성으로 흡수한다. 원심성은 교안대로 더 큰 힘을 낼 수 있지만, 무릎을 덜 굽히면 그 힘이 두 배 넘게 커진다.
