# CHANGES_1108 — 11/8 프로토콜 수정판에 따른 문서 변경

작성 2026-11-08 · 읽는 사람: Claude Code, B, A

팀 문서의 [실험 1 프로토콜] 탭이 11/8 사전 점검 결과로 바뀌어(A 결정 7가지) 이 저장소의 문서를 맞췄다. 이 파일은 ① 바뀐 규칙, ② 코드·분석에 영향이 있는 곳, ③ 파일별 변경, ④ 이미 작업 중인 저장소에 적용하는 방법, ⑤ 덮어쓰지 않는 파일에 붙여 넣을 내용을 담는다. 새로 시작하는 저장소(`walk-music-starter-v2.zip`)에는 이미 모두 반영되어 있어서 ①–③은 참고용이다.

## 1. 바뀐 규칙 (A 결정, 2026-11-08)

1. **폰 위치.** 셋 다 A와 같게, 허리 파우치를 등 쪽에 차고 폰을 가로로 넣는다. 폰 위쪽은 왼쪽 골반 쪽(몸을 정면에서 본 기준)을 향하고 15회 모두 같다. A가 파우치를 찬 사진을 공유한다. '위쪽이 위로'는 지웠다.
2. **앱 설정.** 켤 센서에 보정 안 한 가속도계·자이로스코프(Uncalibrated)를 더했다. 샘플링은 100 Hz(10 ms). 음악 앱 설정(셔플 끔, 전체 반복 켬, 크로스페이드 끔)은 셋이 같게 한다.
3. **측정 구간.** 매 회차 측정 구간 시작·끝에서 2초씩 멈춘다('GPS가 튀면'에서 '매 회차'로 바뀌었다).
4. **걷기 절차.** ① 출발점에서 기록 시작 → ② 바로 폰 화면에서 음악 → ③ 폰을 파우치에 넣고 10초 서기 → ④ 걷기(구간 시작·끝 2초 멈춤, 폰 만지지 않기) → ⑤ 도착점에서 10초 서기 → ⑥ 걷지 않고 폰을 꺼내 기록 종료·음악 끄기.
5. **파일 이름.** 걷는 사람은 이름을 바꾸지 않고 내보낸 그대로 올린다. 대신 기록지의 날짜와 기록 시작 시각(시:분)을 정확히 적는다. 분석용 이름은 분석 쪽이 기록지를 보고 붙인다.
6. **사전 점검.** G1의 '100걸음 ±2'는 사람마다 사전 점검의 100걸음 기록으로 판정한다. B·C는 1회차 전에 10분 리허설과 100걸음 기록을 한다.
7. **스케줄 표.** 실행 스케줄 탭 변수 대응표의 'GPS가 튐' 대응을 '매 회차'로 맞췄다.

바꾼 이유: 폰을 넣은 뒤 걷거나 꺼내는 동작이 걸음으로 잡혀 출발·도착 시각이 틀어졌다. 서 있는 동안 헤드셋으로 튼 음악은 시작 시각이 데이터에 남지 않았다. 폰의 걸음 수 앱은 직접 센 100걸음을 128로 세었다. 내보낸 파일 이름의 시각은 UTC라서 날짜를 베끼면 아침 기록이 전날로 적혔다.

````markdown
| 파일 이름 안의 시각 | UTC (A가 11/8에 확인. 파일로 다시 확인 필요) | | 이름의 시각을 Metadata의 recording epoch time, 센서 첫 `time`과 비교 (SPEC §3.2의 10) |
````

§1 파일 목록의 `Pedometer.csv` 행을 아래 두 행으로 바꾼다.

````markdown
| Pedometer.csv | 있을 것으로 추정(미확인) | | 앱 걸음 수는 직접 센 100걸음을 128로 셌다고 A가 11/8에 보고함. 참고값 (DECISIONS D-30) |
| 보정 안 한 가속도계·자이로(Uncalibrated) | 11/8부터 켠다. 파일·열 이름 미확인 | | 11/7 시범에는 없을 수 있다 (DECISIONS D-32) |
````

이미 채운 값이 있으면 지우지 않고 '메모' 칸만 고친다.

### 5.3 `config/params.toml`

`[constants]` 줄 바로 위에 붙인다.

````toml
[manifest]                           # 기록지(manifest)와 zip을 연결할 때 (SPEC §3.4)
start_time_tol_s = 90                # [초안 D-27] zip의 기록 시작 시각과 기록지 시작 시각(시:분)의 허용 차이. 분 단위로 적으므로 60 s에 앱 조작 지연을 더한 값
````

`[qa]` 안의 주석 세 곳을 아래처럼 바꾼다. 숫자는 바꾸지 않는다.

| 키 | 새 주석 |
|---|---|
| `target_fs_hz` | `# [확정] 앱 설정 100 Hz(10 ms)` |
| `pedometer_tol_pct` | `# [초안] 걸음 수 검출 vs 앱 걸음 수. 참고값이다(앱이 100걸음을 128로 셌다, D-30)` |
| `standing_check_s` | `# [확정] 출발 직전·도착 직후 10초 서 있기(11/8 절차: 폰을 넣은 뒤 서 있기)` |

(Claude Code가 이 값들을 이미 바꿨다면 숫자는 그대로 두고 주석만 맞춘다.)
